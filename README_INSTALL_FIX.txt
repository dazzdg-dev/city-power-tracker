PWA INSTALL FIX V2

In your existing GitHub repository:
1. Replace manifest.webmanifest.
2. Replace sw.js.
3. Create a folder named icons in the repository root.
4. Upload icon-192.png and icon-512.png into icons.
5. Commit to main. Keep index.html and existing records untouched.

Then open the site in Chrome online and reload. Export a CSV backup before clearing any site data.
